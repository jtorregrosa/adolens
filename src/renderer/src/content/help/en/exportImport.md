## Export

Use **Export** to save the current pane's variables to a file (JSON or other formats depending on settings). Useful for backups or sharing.

## Import

Use **Import** to load variables from a file into the current pane. Review the imported variables in the diff view, then push when ready.

## Clone Library

Create a copy of a variable group (name and variables) as a new library in Azure DevOps. Handy for duplicating environments or creating templates.
