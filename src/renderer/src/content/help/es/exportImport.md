## Exportar

Usa **Exportar** para guardar las variables del panel actual en un archivo (JSON u otros formatos según ajustes). Útil para copias de seguridad o compartir.

## Importar

Usa **Importar** para cargar variables desde un archivo en el panel actual. Revisa las variables importadas en la vista de diferencias y publica cuando estés listo.

## Clonar Library

Crea una copia de un grupo de variables (nombre y variables) como nueva library en Azure DevOps. Útil para duplicar entornos o crear plantillas.
