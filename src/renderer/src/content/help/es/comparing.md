El área principal muestra dos paneles (**Izquierdo** y **Derecho**). Cada panel muestra las variables del grupo cargado. Con ambos cargados verás variables añadidas, eliminadas o modificadas.

## Barra de herramientas

Usa la barra de herramientas para:
- **Sincronizar scroll** entre paneles
- **Intercambiar** izquierdo y derecho
- **Actualizar** ambos paneles
- **Descargar** un panel

## En la tabla

- Usa **Copiar a izquierda** / **Copiar a derecha** para mover valores entre lados.
- Activa o desactiva el enmascaramiento de secretos y añade o elimina variables según necesites.

## Leyenda de colores

La vista de comparación usa estos colores para el estado de cada variable:

| Color | Significado |
| ----- | ----------- |
| <span style="display:inline-block;width:14px;height:14px;border-radius:3px;background:#22c55e;vertical-align:middle;margin-right:8px" aria-hidden="true"></span> **Verde** | **Añadida** — variable nueva o presente solo en un lado. |
| <span style="display:inline-block;width:14px;height:14px;border-radius:3px;background:#ef4444;vertical-align:middle;margin-right:8px" aria-hidden="true"></span> **Rojo** | **Eliminada** — la variable ha sido eliminada (pendiente de borrado). |
| <span style="display:inline-block;width:14px;height:14px;border-radius:3px;background:#eab308;vertical-align:middle;margin-right:8px" aria-hidden="true"></span> **Ámbar** | **Editada** — has cambiado el valor o la clave de esta variable localmente. |
| <span style="display:inline-block;width:14px;height:14px;border-radius:3px;background:#3b82f6;vertical-align:middle;margin-right:8px" aria-hidden="true"></span> **Azul** | **Renombrada** — la clave de la variable fue renombrada. |
| <span style="display:inline-block;width:14px;height:14px;border-radius:3px;background:#ec4899;vertical-align:middle;margin-right:8px" aria-hidden="true"></span> **Fucsia (magenta)** | **Modificada** — la misma clave tiene valores distintos en cada lado. |

La barra de estadísticas bajo cada cabecera de panel muestra los conteos de solo aquí, modificadas e idénticas.

## Guardar cambios

Cuando termines de editar, usa **Revisar y publicar** para preparar y publicar los cambios en Azure DevOps. También puedes **Descartar** todos los cambios locales si quieres resetear.
