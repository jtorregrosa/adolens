ADOLens és una **eina d'inspecció de Libraries a Azure DevOps**. Permet veure i editar Variable Groups (Library) en una vista de diferències costat a costat.

Després de connectar amb la URL de la teva organització i un Token d'accés personal, obre **Projectes** i **Libraries** a la barra lateral. Carrega un o dos grups de variables als panells esquerre i dret per comparar-los o editar-los.

Usa la barra d'eines per:
- Sincronitzar el scroll entre panells
- Intercanviar els panells esquerre i dret
- Publicar els teus canvis a Azure DevOps
