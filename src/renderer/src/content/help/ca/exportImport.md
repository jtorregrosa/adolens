## Exportar

Usa **Exportar** per desar les variables del panell actual en un fitxer (JSON o altres formats segons la configuració). Útil per a còpies de seguretat o compartir.

## Importar

Usa **Importar** per carregar variables des d'un fitxer al panell actual. Revisa les variables importades a la vista de diferències i publica quan estiguis llest.

## Clonar Library

Crea una còpia d'un grup de variables (nom i variables) com a nova library a Azure DevOps. Útil per duplicar entorns o crear plantilles.
