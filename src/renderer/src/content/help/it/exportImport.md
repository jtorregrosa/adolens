## Esporta

Usa **Esporta** per salvare le variabili del riquadro corrente in un file (JSON o altri formati in base alle impostazioni). Utile per backup o condivisione.

## Importa

Usa **Importa** per caricare variabili da un file nel riquadro corrente. Rivedi le variabili importate nella vista di confronto e invia quando sei pronto.

## Clona Library

Crea una copia di un gruppo di variabili (nome e variabili) come nuova library in Azure DevOps. Utile per duplicare ambienti o creare modelli.
