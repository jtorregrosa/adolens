A barra lateral lista os teus **Proxectos** e as súas **Libraries** (Variable Groups). Usa a caixa de busca para atopar proxectos ou grupos rapidamente.

## Cargar grupos de variables

- Carga un grupo de variables no panel **Esquerdo** ou **Dereito** cos botóns **L** / **R**.
- Podes marcar libraries como **Favoritos** para acceso rápido.
- A barra lateral pódese expandir ou contraer.

Ao seleccionar un grupo cárganse as súas variables no panel elixido. Podes comparar dous grupos cargando un á esquerda e outro á dereita.
