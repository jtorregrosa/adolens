A área principal mostra dous paneis (**Esquerdo** e **Dereito**). Cada panel mostra as variables do grupo cargado. Con ambos cargados verás variables engadidas, eliminadas ou modificadas.

## Barra de ferramentas

Usa a barra de ferramentas para:
- **Sincronizar scroll** entre paneis
- **Intercambiar** esquerdo e dereito
- **Actualizar** ambos paneis
- **Descargar** un panel

## Na táboa

- Usa **Copiar á esquerda** / **Copiar á dereita** para mover valores entre lados.
- Activa ou desactiva o enmascaramento de segredos e engade ou elimina variables segundo necesites.

## Lenda de cores

A vista de comparación usa estas cores para o estado de cada variable:

A barra de estatísticas baixo cada cabeceira de panel mostra os contadores de só aquí, modificadas e idénticas.

## Gardar cambios

Cando termines de editar, usa **Revisar e publicar** para preparar e publicar os cambios en Azure DevOps. Tamén podes **Descartar** todos os cambios locais se queres reiniciar.
