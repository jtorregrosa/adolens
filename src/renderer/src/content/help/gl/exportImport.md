## Exportar

Usa **Exportar** para gardar as variables do panel actual nun ficheiro (JSON ou outros formatos segundo a configuración). Útil para copias de seguridade ou compartir.

## Importar

Usa **Importar** para cargar variables desde un ficheiro no panel actual. Revisa as variables importadas na vista de diferenzas e publica cando esteas listo.

## Clonar Library

Crea unha copia dun grupo de variables (nome e variables) como nova library en Azure DevOps. Útil para duplicar ambientes ou crear modelos.
